## 📖 项目简介

本工具是一款专为特定 CMS 架构（以 WordPress + Zibll 主题系统为代表）设计的网络安全教学与合规审计桌面应用。在网络攻防演习与安全竞赛场景中，帮助参赛选手快速核验目标系统的账号基线、越权枚举风险、弱口令防护强度及自动化人机验证（Captcha）机制的有效性。

## 🛠️ 技术架构

项目基于现代化的跨平台客户端技术栈开发，具有轻量、跨平台、内存安全与高并发的特性：

| 分层 | 技术选型 | 说明 |
| :--- | :--- | :--- |
| **桌面框架** | **Tauri 2** | 基于操作系统原生 Webview，体积小、占用内存极低，原生调用 Rust 核心能力 |
| **前端界面** | **React 19 + TypeScript + Vite** | 现代化前端工程化架构，类型安全，热重载开发 |
| **UI 组件库** | **Ant Design 5** | 丰富且专业的数据表格、折叠面板、统计看板与表单控件 |
| **后端核心** | **Rust** | 提供内存安全、低延迟、高并发的异步网络处理逻辑 |
| **异步运行时** | **Tokio + Futures** | 负责异步多任务并发执行、限频节流调度与平滑取消 |
| **网络通信** | **Reqwest 0.12** | 异步 HTTP 客户端，支持 Cookie Jar 会话保持、自定义 TLS 证书校验等 |
| **DOM 解析** | **Scraper / Html5ever** | 极速解析 HTML 文档并支持标准 CSS 选择器语法 |
| **本地存储** | **SQLite (Rusqlite)** | 客户端内嵌持久化存储，保存目标站点配置、扫描记录与命中历史 |

## ✨ 核心特性

- **多目标站点管理**：支持多个测试站点独立保存配置，随时切换、编辑与删除。
- **自定义选择器提取**：支持用户名与用户组的 CSS Selector 定制，提供**内置独立页面拾取窗口**（可视化点选网页元素自动生成 Selector）以及单次 Selector 抓取测试。
- **灵活的审计范围**：支持自定义会员 ID 起始与结束范围，过滤特定关键词（如特定权限组）。
- **弱口令检测与滑动验证码交互**：
  - 支持针对命中账号自动测试同名弱口令（`username == password`）；
  - 针对竞赛环境常见的滑块验证码协议，支持自动化挑战参数协商与验签交互。
- **细粒度速率与稳定性控制（高级配置）**：
  - **请求间隔（秒）**：以秒为单位配置请求间隔时间（支持小数如 `0.5s`、`1s` 等），内置自适应节流调度器，防止触发速率限制；
  - **并发控制**：支持 1 ~ 64 并发自由调节；
  - **超时与重试**：可配置 HTTP 超时阈值与失败指数退避重试；
  - **TLS 校验开关**：支持针对靶场自签名证书站点关闭证书严格校验。
- **实时看板与数据导出**：实时统计扫描进度、成功数与弱口令命中状态，支持状态详情查看并一键导出标准 UTF-8 CSV 报告。

## 🚀 快速上手

### 1. 环境准备

确保本机已安装以下开发环境：
- **Node.js**: v18.0.0 或更高版本
- **Rust**: 1.77.0 或更高版本（包含 `cargo`）
- 对应操作系统的 Tauri 依赖（macOS 需安装 Xcode 命令行工具；Windows 需安装 C++ 构建工具与 WebView2）。

### 2. 安装与运行

```bash
# 1. 克隆代码仓库
git clone https://github.com/listensay/trytryuser.git
cd trytryuser/app

# 2. 安装前端依赖
npm install

# 3. 启动开发环境（启动前端 Vite 与 Tauri 桌面窗口）
npm run tauri dev
```

### 3. 项目打包

```bash
# 构建桌面可执行安装包（macOS 为 .dmg/.app，Windows 为 .msi/.exe）
cd app
npm run tauri build
```

打包完成后，安装包将生成在 `app/src-tauri/target/release/bundle/` 目录下。

## 📝 使用流程说明

1. **添加站点**：在左侧站点列表点击「添加站点」，输入靶场根域名（如 `http://192.168.1.100`）。
2. **基础配置**：
   - 填写作者页路径（默认为 `/author/{id}`）；
   - 输入要审计的 ID 范围（如起始 ID `1`，结束 ID `500`）；
   - 配置或通过「从页面选取」获取用户名和用户组 CSS Selector，点击「测试获取」验证能否正确解析。
3. **高级配置**：
   - 根据靶场网络与环境承载能力设置**并发数**（如比赛网络环境敏感建议设为 `1` ~ `4`）；
   - 设置**请求间隔（秒）**（如 `1` 秒或 `2` 秒，避免请求频次过高）；
   - 按需开启弱口令检测与对应字段定义。
4. **开始审计**：
   - 点击「开始审计」按钮，在右侧结果表格与日志区域实时查看检测状态；
   - 如需中途停止，可随时点击「停止扫描」；
   - 扫描结束后，点击「导出 CSV」保存审计结果报告。
